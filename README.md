# 🌸 Darling Bot — Zero Two Edition (Darling in the Franxx)

Bot Discord profissional, completo, original e moderno inspirado na **Zero Two** (*Darling in the Franxx*).

---

## 🚀 Funcionalidades Principais

- **Sistema Social & Perfil:** Comandos de perfil personalizados com a temática da Zero Two (`/perfil`), bio, títulos, nível e reputação.
- **Economia Completa:** Sistema de D-Coins (`/saldo`), carteira, banco, transações atômicas e proteção anti-exploits.
- **Arquitetura Escalável:** Desenvolvido em **TypeScript**, **Discord.js v14**, **MongoDB (Mongoose)**, com separação estrita em Models, Services e Commands.
- **Identidade Visual Temática:** Todos os embeds, mensagens e respostas usam a identidade visual e frases marcantes da Zero Two ("*Você quer ser meu Darling?*").

---

## 🚀 Como Iniciar (Modo Rápido)

Para uma inicialização completa e automatizada, utilize o script fornecido:

```bash
chmod +x start.sh
./start.sh
```

Para instruções detalhadas de configuração, comandos e sistemas, consulte o **[MANUAL.md](./MANUAL.md)**.

---

## 📦 Instalação Manual

Se preferir realizar o setup passo a passo:

1. **Pré-requisitos:** Node.js 22+ e MongoDB.
2. **Dependências:** `npm install`
3. **Configuração:** Preencha o arquivo `.env`.
4. **Build:** `npm run build`
5. **Deploy de Comandos:** `npm run deploy`
6. **Start:** `npm start`
